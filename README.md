# Long-Short-Term-Memory-for-WInd-Profile-Prediction
The data file that will be used in this LSTM model was taken from the design of the model applied in the article doi.org-10.5194-wes-2023-104
To get the raw data, please consult to original author of the paper below:
Leme Beu, C. M. and Landulfo, E.: Machine-learning-based estimate of the wind speed over complex terrain using the long short-term memory (LSTM) recurrent neural network, Wind Energ. Sci., 9, 1431–1450, https://doi.org/10.5194/wes-9-1431-2024, 2024.
